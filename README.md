# Smart Seafood Chain — B6B36OMO semester project

Discrete-event **seafood supply chain simulation** for the *Objektový návrh a modelování* course (B6B36OMO).

**Stack:** Java 21, Maven, Jackson YAML, Lombok.

**Highlights:** blockchain traceability, YAML-driven configuration, discrete-time simulation, reporting, GoF patterns (Factory, Observer, Memento, Command, Strategy).

```bash
mvn -f Smart-Seafood-Chain/pom.xml package
java -jar Smart-Seafood-Chain/target/smart-seafood-chain.jar
```
